# RedeemChat API (сервер каталога)

Это лёгкий сервер для RedeemChat: общий список публичных серверов,
счётчик пользователей, каталоги стикерпаков и конфигураций тем, проверка обновлений.

## Как запустить бесплатно на Render
1. Залей эти файлы (api.js, package.json, render.yaml) в репозиторий на GitHub.
2. На render.com → New → Web Service → подключи этот репозиторий.
3. Runtime: Node. Start Command: `node api.js`. План: **Free**. Create.
4. Render выдаст адрес вида https://имя.onrender.com
5. Вставь этот адрес в приложении: Настройки → Сеть → «Адрес сервера каталога (API)».

Порт берётся автоматически из переменной окружения PORT (Render задаёт её сам).

Замечания бесплатного тарифа Render:
- Сервер засыпает при простое — первый запрос после паузы грузится ~30–60 сек.
- Диск временный: при перезапуске опубликованные паки/конфиги и список
  пользователей могут обнулиться. Для хобби-проекта это нормально.
